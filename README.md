# inhouse agency — сайт

Лёгкий одностраничный сайт без фреймворков: HTML + CSS + немного JS. Вес страницы около 110 КБ вместе со шрифтом.

## Структура

```
index.html            главная
privacy.html          политика конфиденциальности (152-ФЗ)
consent.html          согласие на обработку ПД (отдельным документом, как требует 152-ФЗ с 01.09.2025)
404.html              страница «не найдено»
send.php              обработчик формы для PHP-хостинга (почта + Telegram-бот)
assets/css/style.css  стили (цвета и размеры — в :root вверху файла)
assets/js/main.js     меню, анимации, маска телефона, форма, цели Метрики
assets/img/           логотип (SVG), светлая версия логотипа, OG-картинка
assets/fonts/         шрифт Onest (вариативный, кириллица + латиница)
.htaccess             редиректы и кэш для Beget (на GitHub Pages игнорируется)
```

## Что поменять под себя

- **Яндекс.Метрика.** Вставь код счётчика в `<head>` файла `index.html` (там стоит комментарий), а номер счётчика — в `CONFIG.metrikaId` в `assets/js/main.js`.
  Цели, которые отправляются сами: `form_submit`, `form_telegram`, `click_phone`, `click_telegram`, `click_email`.
- **Почта.** Везде указан `info@inhouseagency.ru`. Ящик нужно создать в панели Beget → Почта (MX уже смотрят на Beget). Для `send.php` там же заведи `noreply@inhouseagency.ru`.
- **Тексты** — прямо в `index.html`, всё на русском, без шаблонизаторов.

## Форма заявки

- На **GitHub Pages** PHP не работает. Поэтому после отправки посетитель видит кнопку «Отправить в Telegram»: текст заявки копируется, открывается чат с @Anthon_Ovdin.
- На **PHP-хостинге** (Beget) работает `send.php`: заявка уходит на почту, а если заполнить `TG_TOKEN` и `TG_CHAT` — ещё и в Telegram через бота. Запасной вариант не понадобится.

## Домен inhouseagency.ru → GitHub Pages

NS-серверы не меняем, DNS остаётся на Beget.

1. В панели Beget → DNS → inhouseagency.ru:
   - удалить A-запись `5.101.153.129`;
   - добавить четыре A-записи: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - для `www` удалить A-записи и добавить CNAME `anthon88-nch.github.io.`
   - MX и TXT не трогать — это почта.
2. В репозитории: Settings → Pages → Custom domain → `inhouseagency.ru` → Save. Появится файл `CNAME`.
3. Когда DNS обновится (от 15 минут до суток), включить **Enforce HTTPS** там же.

## Переезд со старого сайта i-tend.ru

Чтобы не потерять позиции, на хостинге i-tend.ru положи в `.htaccess`:

```apache
RewriteEngine On
RewriteRule ^(.*)$ https://inhouseagency.ru/ [R=301,L]
```

Потом в Яндекс.Вебмастере добавь inhouseagency.ru и укажи переезд сайта со старого домена.
